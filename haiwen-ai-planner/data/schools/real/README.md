# Real school dataset

`real-school-data-v0.1` is generated by
`scripts/school-data/seed-real-dataset.ts` from the committed official-source
extracts. Regenerate after editing that script, then validate before import.

Do not:

- label `TEST_FIXTURE` data as `OFFICIAL`;
- rewrite a 2026 policy as a 2027 policy;
- record a key fact without a `SourceDocument`;
- record `Evidence` whose span cannot be verified against source text;
- present a third-party article as an official fact source.

Prepare future normalized data through:

```text
Official source
↓
Normalized SourceDocument
↓
University / Department / Program
↓
Policy
↓
Evidence
↓
pnpm schools:validate --dataset=real
```

The data can be imported with `pnpm schools:import --dataset=real`.
