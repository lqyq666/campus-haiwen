# Scoring Model v0.1

> 当前 v0.1 规则是产品工程 baseline，尚未经过万学海文专家历史数据校准，不得解释为真实录取概率。

## 评分定义

- 保研分：学生自身当前保研竞争力 baseline，不包含学校推免率或真实录取概率。
- 考研分：当前准备度与基础竞争力，不预测上岸概率。
- 所有维度、总分与 confidence 均由确定性规则计算，范围为 0–100。

## 权重与关键阈值

- 保研：学业 40、英语 15、科研 20、竞赛 15、成果与实践 10。
- 排名：前 3/5/10/15/20/30% 分档；缺排名时 GPA 仅作低置信度替代。
- 英语：CET6 优先，按 550/520/500/425 分档；缺 CET6 时使用 CET4 辅助。
- 科研：按最强经历的角色、时长、成果及少量数量加分。
- 竞赛：按校级、省级、国家级、国际级评估，不绑定具体比赛名称。
- 考研：学业基础 25、英语基础 20、准备时间 20、学习投入 20、目标清晰度 15。

## Path Router

- 缺年级、学业记录或英语信息时返回 `INSUFFICIENT_DATA`。
- 大一/大二显式保留提升窗口；两条路径任一具备基础时优先 `DUAL_TRACK`，极强保研基础可返回 `RECOMMENDATION`。
- 大三根据两项评分的相对优势选择保研、考研或双轨。
- 大四/毕业阶段仅在排名和保研竞争力均强时保留保研路径，否则聚焦 `POSTGRAD_EXAM`。

## 已知局限

- GPA 缺少统一满分制信息，只能作为排名缺失时的弱替代。
- 未采集数学、政治、专业课基础，考研 confidence 上限受限且 missingData 始终提示这些项目。
- 未使用学校推免率、目标院校招生政策、专业难度或历史录取数据。

## 下一版待校准项

- 使用海文专家历史样本校准权重、阈值与风险文案。
- 增加 GPA 满分制及数学、专业课、政治基础字段。
- 在 Evidence 数据就绪后独立建立院校适配，不反向污染学生竞争力评分。
